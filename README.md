# kevindemo.github.io

Source of Kevin Chen's freelance homepage, served by GitHub Pages at https://kevindemo.github.io.

Plain HTML and CSS with no build step, no framework, no JavaScript and no external requests: fonts are system stacks, and there are no analytics or trackers. Light and dark modes follow the visitor's system setting.

To preview it, open `index.html` in a browser, or run `python -m http.server` in this folder.

The CV at `/cv/` is served from a separate repository. This site only links to it, and because this repo has no `cv` folder the two do not conflict.

The result figures on the page come from the READMEs of the two demo repositories. Update them here if those results change.

When the Upwork profile exists, add its link at the placeholder comment in the Contact section of `index.html`.
